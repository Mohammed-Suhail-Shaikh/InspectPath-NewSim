# Design: Defect Model

## Layout
```
ml/defect/
  prepare_data.py   build CSVs + test_files.txt
  common.py         classes, shared eval transform (padding + resize), model builder
  train.py          training loop, saves artifacts/best.pt
  evaluate.py       one test run, writes results.md
  tier.py           pure tier(detected) function
  api/main.py       FastAPI app
  tests/            tier + API tests
  splits/           train.csv, val.csv, test.csv, test_files.txt
  artifacts/        best.pt (git-ignored)
  results.md        generated by evaluate.py
```

## Key decisions
- **Single source of truth:** `common.py` holds the class list and the eval transform
  (pad to square, resize, normalize). Train-time validation, `evaluate.py` and the API all import it.
- **Split by source photo:** source photo is read from the patch filename/metadata
  (to be confirmed after data inspection). Groups are shuffled with a fixed seed and assigned whole.
- **Loss:** `BCEWithLogitsLoss(pos_weight)`; weight per class = negatives / positives on the train set.
- **Model choice:** `--arch resnet18|mobilenet` swaps the backbone, final layer has 5 outputs
  (or 3 with `--groups3`).
- **Groups3 mapping:** surface = crack OR efflorescence, corrosion = corrosion_stain,
  structural = spallation OR exposed_bars. Class names are stored in the checkpoint.
- **API:** loads checkpoint once at startup. Env vars (names match `.env.example` on repo-scaffold): `MODEL_PATH`,
  `CONFIDENCE_THRESHOLD` (default 0.5), `MOCK_MODEL`, `CORS_ORIGINS`. Mock mode derives scores deterministically from the image bytes.
- **Tier:** `tier.py` has no imports from the model code, so it is trivial to test.
