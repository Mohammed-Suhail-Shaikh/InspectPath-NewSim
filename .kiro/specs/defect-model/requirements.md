# Requirements: Defect Model (ml/defect/)

Owner: Zaiba. Scope: only `ml/defect/` and this spec folder.

## Goal
Given a concrete patch image, predict which of 5 defects are present and map them to a risk tier.

## Requirements

1. **Data prep.** Build train/val/test CSVs from the CODEBRIM classification data.
   Columns: path + crack, spallation, exposed_bars, efflorescence, corrosion_stain. All zeros = background.
   - Split by source photo. No photo appears in two splits. Fixed seed.
   - Zero overlap between splits is asserted in code.
   - Test filenames are saved to `ml/defect/splits/test_files.txt` (committed, images are not).
2. **Training.** Pretrained ResNet-18 (MobileNet via flag), 5 sigmoid outputs, weighted BCE for rare classes.
   - Thin patches are padded to square, then resized.
   - One shared eval transform is used by validation, evaluation and the API.
   - Best epoch is chosen by validation macro-F1. The test set is never used in training.
   - `--groups3` fallback: surface, corrosion, structural. Default is 5-class.
3. **Evaluation.** One run on the test split at threshold 0.5. `results.md` is generated by the script
   with per-class precision, recall, F1, support, macro-F1, takeaways and limitations.
4. **Tier rule.** high if exposed_bars or spallation; else medium if corrosion_stain;
   else low if crack or efflorescence; else none.
5. **API.** `POST /predict` (file or base64) returns the exact agreed JSON shape.
   `GET /health`. CORS on. Model loads once at startup. Config by env vars. `MOCK_MODEL=1` gives fake responses.
6. **Docs.** `docs/readme/defect.md` under 250 words, with dataset citation and honest limitations.

## Out of scope
Anything not in the brief. Dataset images in git. API keys or secrets.
